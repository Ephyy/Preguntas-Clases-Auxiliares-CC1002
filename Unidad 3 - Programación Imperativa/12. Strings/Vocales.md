# Vocales

Cree la función ```contarVocales(S)```, que recibe un string que puede representar una palabra o frase, y la función debe retornar el número de vocales (letras `a`, `e`, `i`, `o`, `u`) que posee. Ejemplos:
- ```contarVocales('dinero')``` entrega ```3```
- ```contarVocales('un dia vi una vaca')``` entrega ```8```
