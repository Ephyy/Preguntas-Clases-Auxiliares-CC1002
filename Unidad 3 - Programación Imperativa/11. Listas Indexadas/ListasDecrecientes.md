# Lista Decreciente

Cree la función ```esDecreciente(L)```, que recibe una lista indexada que contiene números, y entrega True si es que cada uno de los elementos es estrictamente mayor al elemento siguiente. Ejemplos:

- ```esDecreciente([100, 56, 45, 27, 9, 5, 1])``` entrega ```True```
- ```esDecreciente([100, 100, 45, 27, 9, 5, 1])``` entrega ```False```

**Indicación:** Su función no debe modificar/mutar la lista original recibida por parámetro.
