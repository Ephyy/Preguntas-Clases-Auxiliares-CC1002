# Ordenar

Cree la función ```ordenarLista(L)``` que recibe una lista indexada y la **muta** ordenándola de menor a mayor.

**Indicaciones:**
- No puede crear una nueva lista para su solución, ni siquiera como lista auxiliar, todos los cambios se deben realizar sobre la lista `L`.
- Tampoco puede usar la función ```sort()``` o ```sorted()``` de listas indexadas o similares.

*Hint: Use convenientemente en un ciclo la función ```min()``` en conjunto con slicing, para resolver el problema.*
