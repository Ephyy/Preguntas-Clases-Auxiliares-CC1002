#  Contiene solo unos 1️

Programe una función recursiva ```contieneSoloUnos(n)``` que dado un número entero positivo de largo variable, entregue ```True``` si contiene solo números 1, o ```False``` en caso contrario.

Por ejemplo:
- ```contieneSoloUnos(1262)``` entrega ```False```
- ```contieneSoloUnos(111111111)``` entrega ```True```
