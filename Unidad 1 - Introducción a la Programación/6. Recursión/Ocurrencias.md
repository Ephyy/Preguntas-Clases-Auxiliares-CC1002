# Ocurrencias 🔎
Programe la función ```ocurrencias(n, b)``` que dado un número entero positivo `n` y un dígito `b` entre 0 y 9, entrega cuantas veces aparece el dígito `b` en el número `n`. Ejemplos:

- ```ocurrencias(234355323, 3)``` entrega ```4```
- ```ocurrencias(234355323, 8)``` entrega ```0```
